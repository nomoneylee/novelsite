# 小說記憶系統

你已被注入 `novel-memory` 技能。本技能指導如何使用工作區文件系統作為小說創作的持久化記憶。

---

## 文件結構

```
novel/{書名}/
├── plan.md              # 總控大綱（由 novel-worldbuilding 生成）
├── 設定/
│   ├── characters.md    # 人物檔案（全部角色）
│   ├── world.md         # 世界觀規則
│   ├── foreshadowing.md # 伏筆台帳（唯一動態真相來源，見下方說明）
│   ├── timeline.md      # 時間線
│   ├── relations.md     # 人物關係網絡
│   └── story-so-far.md  # 全書滾動總摘要（現況快照，非逐章堆疊）
├── 正文/
│   ├── 第1章_標題.md
│   └── ...
├── summary/
│   ├── chapter_01.md    # 章節摘要
│   └── ...
├── review/
│   ├── chapter_01_review.md  # 審核報告（novel-review 產出）
│   └── ...
└── research/
    ├── {主題}.md         # 調研筆記（novel-research 產出）
    └── ...
```

所有路徑基於工作區根目錄。**文件即記憶，目錄即分類。**

**單一真相來源原則**：同一資訊只能有一處動態維護的權威記錄，其餘引用處只做參考或連結，不重複同步。目前適用：
- 伏筆狀態 → 唯一來源是 `設定/foreshadowing.md`。`plan.md` 的「主線伏筆規劃」表只在初次規劃時填寫，一旦開始寫作即視為歷史草案，不再逐章同步更新。
- 全書現況 → 唯一來源是 `設定/story-so-far.md`。`summary/chapter_XX.md` 是不可覆寫的歷史記錄，`story-so-far.md` 才是永遠反映「目前」的現況快照。

---

## 記憶分類

### 1. 靜態設定（長期有效）

存儲於 `novel/{書名}/設定/` 目錄：

| 文件 | 內容 |
|------|------|
| `characters.md` | 人物檔案：姓名、年齡、外貌、性格、背景、動機、能力 |
| `world.md` | 世界觀：力量體系、科技水平、政治制度、地理環境 |
| `relations.md` | 關係網絡：角色間關係類型、陣營、勢力層級 |

### 2. 動態日誌（按章推進）

| 文件 | 內容 |
|------|------|
| `summary/chapter_XX.md` | 每章摘要：核心事件、角色狀態變化、新/回收伏筆 |
| `設定/story-so-far.md` | 全書現況快照：主線目前進度、角色動態資源與狀態面板（資源/能力/健康/道具）、各角色當前狀態一覽、未決衝突、活躍支線清單（**覆寫式更新，非追加**，永遠只反映「現在」） |
| `設定/foreshadowing.md` | 伏筆台帳：ID、描述、埋設章節、預計回收章節、狀態、關聯角色（**動態追蹤唯一來源**） |
| `設定/timeline.md` | 時間線：故事內時間進度、各章時間跨度 |
| `設定/characters.md` | 角色當前狀態（追加更新，不覆蓋歷史） |

## 角色動態資源與狀態面板規範（全題材通用）

長篇創作最容易出現「前章重傷、後章生龍活虎」或「道具與資源憑空增減」的斷層。因此，在 `設定/story-so-far.md` 中必須維護一組**動態資源與狀態面板**。此面板依據各小說題材自行對應，常見範例：

* **玄幻/修仙/仙俠**：當前境界階層、體內靈力/真元儲備（百分比）、暗傷與經脈狀態、法寶/符籙/丹藥剩餘庫存、近期結仇/宗門因果。
* **科幻/網遊/無限流**：核心數值指標（如體力/神經負荷/San值/魔力）、裝備槽與技能卡組配置、消耗性物資/藥品/彈藥存量、系統即時聲望與點數。
* **懸疑/驚悚/推理**：主角體力與傷勢、心理壓力/恐懼值、手頭掌握的物證/防身道具、關鍵嫌疑人動向、剩餘生存時限。
* **都市/商戰/職場**：可調用流動資金、持股比例、人脈資源信用值、待履行的重要承諾/合約、當前面臨的公關或訴訟危機。
* **歷史/軍事/架空**：控制兵力與糧草存量、地盤疆域、朝堂威望/君臣猜忌度、重要盟約與承諾。

**面板格式（寫入 `設定/story-so-far.md`）**：
```markdown
## 核心角色即時動態面板
### [主角名]
- **當前生理/心理狀態**：[健康/負傷部位/疲勞度/精神狀態]
- **核心能力/等級階位**：[當前修為/職業等級/特殊狀態]
- **關鍵資源/裝備/庫存**：[具體道具/消耗品剩餘量/武器裝備]
- **手頭重大未決承諾/死線**：[對某人的誓言/倒數計時危機]
```

## 操作規範

### 讀取（每章開始前必做）

1. **先讀全書現況與即時面板**：`設定/story-so-far.md`（主線進度、角色即時動態面板、活躍支線一覽）——掌握主角當前身體是否有殘留傷勢、手頭有哪些可調用道具與數值，防止無中生有或傷勢憑空消失。
2. 讀取近 3 章摘要：`summary/chapter_XX.md`（僅需近期銜接細節，不需通篇翻閱全部歷史章節）
3. 讀取角色性格與狀態：`設定/characters.md` 核心檔案及 `plan.md` 的「角色速寫」區塊（口癖、性格關鍵詞、不為之事）
4. 讀取語言規範與大綱條目：`plan.md` 的「語言與文字規範」及本章條目與容量目標
5. 讀取未回收伏筆：`設定/foreshadowing.md` 中狀態為「未回收」的條目
6. 讀取時間線：`設定/timeline.md` 獲取當前故事時間
7. **讀取活躍支線狀態**：在 `plan.md` 的「支線故事規劃」表格中，找出狀態為「進行中」的支線，確認本章在該支線弧中的位置與待推進的懸念或衝突
8. **確認上一輪審核狀態**：若 `review/` 目錄下有本章前一版本或關聯章節的審核報告且狀態為「待修正」，須先確認修正是否已完成（見 novel-review 技能的回修流程），避免在未解決的問題上疊加新內容

**查詢技巧**：當需要搜索特定設定時，用 grep 在 `設定/` 目錄及 `plan.md` 下搜索關鍵詞。全書現況一律先查 `story-so-far.md`，不足時才逐章翻找。

### 寫入（每章完成後必做）

1. 創建本章摘要文件：`summary/chapter_XX.md`
2. **覆寫更新** `設定/story-so-far.md`：
   - 更新主線進度一句話摘要
   - **更新核心角色即時動態面板**（更新消耗品、負傷與戰力狀態）
   - 更新變動角色的現況、新增/移除的活躍支線與未決衝突
   - 此文件只保留「現在」，舊狀態由 summary/ 保存，不在此堆疊歷史
3. 更新角色狀態：在 `設定/characters.md` 中追加變化記錄
4. 更新伏筆台帳：`設定/foreshadowing.md` 中標記新增/回收（唯一動態來源，不回頭同步 `plan.md` 的規劃表）
5. 推進時間線：`設定/timeline.md` 中記錄本章時間

### 初始化（新書啟動 / 從 plan.md 解構）

當啟動一部新書，或已有一份詳實完備的 `plan.md` 總控大綱時，執行以下初始化建立記憶庫：

1. **目錄建構**：確認 `novel/{書名}/設定/`、`review/`、`research/`、`正文/`、`summary/` 目錄均已建立。
2. **解構 characters.md**：自 `plan.md` 提取所有核心角色檔案、口癖、不為之事，寫入 `設定/characters.md`。
3. **解構 world.md**：自 `plan.md` 提取世界底層法則、力量/技術體系、陣營階層、代價約束，寫入 `設定/world.md`。
4. **解構 foreshadowing.md**：自 `plan.md` 的初始伏筆規劃表格，初始化 `設定/foreshadowing.md`，所有初期伏筆標註為「⚪ 待埋設」。
5. **初始化 story-so-far.md**：
   - 記錄故事開篇前的世界總貌。
   - 建立核心角色的第 0 版即時動態面板（開篇時的初始能力、身體狀況、初始資源）。
   - 列出初始開放的主線與第 1 卷活躍支線。
6. **初始化 timeline.md & relations.md**：建立時間原點與最初人際關係網絡。

## 操作原則

1. **即時記錄**：定義新實體/規則時立即寫入對應文件
2. **更新同步**：設定演變時及時更新，保持文件與正文一致
3. **動態面板嚴謹**：數值、道具、傷殘狀態嚴格以 `story-so-far.md` 為準，杜絕憑空獲取或憑空自癒
4. **避免冗餘**：只記錄核心的、長期有效的資訊
5. **防遺忘**：依賴文件而非記憶，第 100 章時讀文件就能回憶第 1 章的設定
6. **追加優先**：角色狀態變化用追加而非覆蓋，保留變化歷史

## 伏筆台帳格式

`設定/foreshadowing.md` 中每條伏筆格式：

```markdown
### F001: {伏筆描述}
- 埋設：第 X 章，{具體場景描述}
- 預計回收：第 Y 章
- 狀態：未回收 / 已回收（第 Z 章）
- 關聯角色：{角色名}
```

## 查询流程

```
需要核實設定 → 讀取 設定/ 下對應文件 → grep 關鍵詞定位 → 獲取資訊
需要全書現況 → 讀取 設定/story-so-far.md → 不足時再讀 summary/ 近幾章摘要
需要前文回顧 → 讀取 summary/ 下近幾章摘要 → 了解上下文
需要全局檢查 → 遍歷 設定/ 全部文件 → 交叉驗證一致性
```
