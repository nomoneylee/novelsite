# 小說架構設計 — 模板參考

## 1. plan.md 總控大綱模板

```markdown
# {書名}

## 基本信息
- **類型**：[奇幻/科幻/懸疑/言情/歷史/...]
- **敘事視角**：[第一人稱/第三人稱限知/第三人稱全知]
- **預計規模**：[X 萬字 / X 章]
- **基調風格**：[簡述整體風格和情感基調]

## 核心衝突
[一句話概括主線矛盾]

## 故事梗概
[200-500 字概述整個故事]

## 支線故事規劃

| 支線 ID | 支線名稱 | 主要人物 | 篇幅（章） | 起始章 | 結束章 | 主線關聯 | 當前狀態 |
|---------|---------|---------|-----------|-------|-------|---------|----------|
| S001 | [支線名] | [人物] | [N章] | 第X章 | 第Y章 | [如何影響主線] | 未開始/進行中/已完結 |

> **支線規模建議**：小型 3-5 章 / 中型 6-15 章 / 大型 16-30 章。每條支線應具備尌立的起承轉合，不得以「每章一個小事件」代替支線弧線。

---

## 卷章結構

### 卷結構說明
- **卷主題**：[本卷核心矛盾與主題弧線]
- **戰力/地位錨點**：[本卷角色階位、資源規模或社會地位進展]
- **本卷活躍支線**：[S001, S002 等]

---

### 單章大綱標準格式（二選一）

#### 選項 A：基礎大綱模板（適用輕量敘事、短篇或日常推進）
```markdown
#### 第 1 章：[章名]
- **所屬支線**：[主線 / S001 / S002]
- **支線進度**：[該支線弧第幾章，處於哪個階段，例：S001 第1/8章，衝突引發段]
- **核心任務**：[本章必須完成的劇情推進]
- **關鍵場景**：[2-3 個核心場景]
- **埋設伏筆**：[需要在本章埋下的線索]
- **回收伏筆**：[本章需要回應的前文線索]
```

#### 選項 B：工業化七大維度細綱模板（推薦：高資訊密度、智鬥博弈、多方角力之長篇巨作）
```markdown
* **第 X 章：[章節標題]**
  * **場景與時空錨點**：[具體環境、光影、感官氛圍與開篇切入點，明確時間與空間坐標]
  * **登場人物與心理防線**：[登場角色、各自立場與隱秘動機、不可退讓的利益底線]
  * **關鍵交鋒台詞（必寫指示）**：
    > [角色A]：「[極具角色辨識度的交鋒台詞或刺探性問句]」
    > [角色B]：「[隱含潛台詞的反擊或利益交換，非口水廢話]」
  * **情節推進與多方博弈**：[核心衝突展開、至少兩方或三方的動態角力過程、阻礙與破局動作]
  * **信息差與機制破局**：[利用情報優勢、專業知識、環境特性或規則漏洞實現降維打擊/巧妙破局]
  * **收益反饋與代價結算**：[戰利品/修為境界/資金合約/公關戰果；同步結算消耗代價（體力、理智、負傷、資源反噬）]
  * **所屬支線與伏筆追蹤**：所屬支線：[主線 / S00X]；埋設伏筆：[FXXX]；回收伏筆：[FYYY]
```

> **各題材化用指南（泛用）**：
> * **玄幻/仙俠**：【信息差】= 熟知古經秘辛/法陣破綻；【收益與代價】= 突破境界/靈力枯竭/經脈暗傷。
> * **都市/商戰**：【信息差】= 掌握財務造假證據/監管新規漏洞；【收益與代價】= 收購股權/資金鏈緊繃。
> * **懸疑/推理**：【信息差】= 法醫微量物證/心理盲區；【收益與代價】= 鎖定真兇線索/生存倒數計時危機。
> * **科幻/網遊/無限流**：【信息差】= 原作名場面/先知機轉/BOSS盲區；【收益與代價】= 獲取專屬裝備與技能/神經突觸負荷或San值反噬。
> * **歷史/架空軍事**：【信息差】= 斥候密報/敵軍糧道虛實；【收益與代價】= 陣斬敵將收復要塞/朝堂結仇引起君王猜忌。

## 4. 伏筆台帳格式

唯一動態來源為 `設定/foreshadowing.md`（plan.md 表格僅為初稿，不重複維護）：

```markdown
| ID | 伏筆內容 | 埋設章節 | 預計回收 | 實際回收 | 狀態 | 備註 |
|----|---------|---------|---------|---------|------|------|
| F001 | [描述] | 第X章 | 第Y章 | - | 🔵 已埋設 | |
| F002 | [描述] | 第X章 | 第Y章 | 第Y章 | ✅ 已回收 | |
| F003 | [描述] | - | 第X章 | - | ⚪ 待埋設 | |
```

**狀態說明**：
- ⚪ 待埋設：計劃中尚未寫入正文
- 🔵 已埋設：已在正文中埋下線索
- ✅ 已回收：已在後文中回應/揭示
- 🔴 遺漏：超過預計回收章節仍未回收（需要處理）
```
