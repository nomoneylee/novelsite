# 深度調研技能

你已被注入 `novel-research` 技能。你的職責是為小說創作提供高品質的信息檢索和邏輯推演支持。

---

## 1. 真實細節檢索

### 定位

搜索真實世界資訊，為虛構敘事注入可信度。**細節是謊言的偽裝，讓虛構更可信。**

### 使用場景

| 場景 | 示例查詢 |
|------|---------|
| 歷史場景 | "19世紀倫敦東區街道布局和日常生活" |
| 專業知識 | "氰化物中毒的症狀和發作時間" |
| 地理文化 | "京都祇園花街的建築風格和藝伎文化" |
| 軍事/武器 | "二戰德國U型潛艇內部結構" |
| 醫學/科學 | "失血過多時人體的生理反應" |
| 社會制度 | "古羅馬共和國的元老院運作方式" |

### 使用方法

通過可用的搜索工具（web_search 等）進行檢索：
1. 構造明確的搜索查詢（中文或英文均可）
2. 獲取搜索結果
3. 提取關鍵細節融入敘事

### 使用原則

- **精準查詢**：查詢語句要具體，避免過於寬泛
- **提取細節**：從搜索結果中提取具體的名稱、數字、描述
- **融入敘事**：將事實自然地編織進故事，不要像百科全書式的羅列
- **適度使用**：不是每個場景都需要查證，只在需要可信度的關鍵場景使用

## 2. 邏輯推演

### 定位

用於複雜情節的深層邏輯推演，確保故事經得起推敲。

### 使用場景

| 場景 | 推演內容 |
|------|---------|
| 複雜反轉 | 提前驗證反轉是否有足夠鋪墊，讀者是否能接受 |
| 多線收束 | 推演多條故事線如何自然匯合 |
| 智鬥環節 | 設計攻防邏輯，確保雙方行為合理 |
| 邏輯驗證 | 檢查情節因果鏈，發現潛在漏洞 |
| 時間線推演 | 驗證多角色同一時間段的行動是否衝突 |
| 動機分析 | 推演角色在特定情境下的合理反應 |

### 使用原則

- **問題明確**：將待推演的問題清晰地表述為一個具體命題
- **分步推演**：逐步推理，不要一次給出太大的命題
- **批判採納**：推演結果是參考，用創作者的判斷力篩選
- **留有餘地**：推演出多個可能路徑時，選最有戲劇性且合邏輯的那個

## 3. 風格參考

### 使用場景

- 卡文需要靈感時
- 需要參考特定場景描寫方式時
- 學習某種敘事風格時

### 工作流

1. 在工作區 `novel/{書名}/` 或參考素材目錄中檢索相關風格參考
2. 分析檢索結果：韻味、節奏、手法、切入點
3. 參考而非抄襲

---

## 調研與創作的結合

### 「參考而非抄襲」原則

1. **搜索結果**：提取事實細節（名稱、數據、描述），用自己的語言重新敘述
2. **風格參考**：學習風格和手法（節奏、視角、氛圍營造），用自己的內容重新創作
3. **邏輯推演結果**：採納邏輯結論，但用創作者的方式表達

### 調研強度選擇

| 場景類型 | 調研強度 | 方法 |
|----------|---------|------|
| 日常對話/情感場景 | 低 | 無需調研 |
| 專業知識相關場景 | 中 | 網絡檢索 |
| 複雜反轉/多線匯合 | 中 | 邏輯推演 |
| 歷史/真實場景還原 | 高 | 檢索 + 推演 |
| 卡文/風格探索 | 中 | 風格參考 |

---

## 結果存放規範

- **一次性調研筆記**（背景知識、專業細節、風格參考等原始檢索結果）→ 統一寫入 `novel/{書名}/research/{主題}.md`，檔名用主題關鍵詞，方便日後同主題搜尋前先查有無現成筆記
- **直接影響設定的結論** → 除了留存於 research/ 筆記，還須回寫入 `設定/` 對應文件（world.md 的世界規則、characters.md 的角色背景等，見 novel-memory 技能），並在 research 筆記中註明「已回寫至 {文件路徑}」，避免下次調研重複勞動
- 判斷原則：這份資訊未來會不會被反覆查詢/影響一致性？會 → 才需回寫設定文件；只是單次場景的背景細節 → research/ 筆記即可,不必回寫

## 注意事項

1. **不要過度調研**：調研是為創作服務的，不要陷入無休止的搜索
2. **不要堆砌細節**：搜索到的資訊要自然融入敘事，不要變成知識百科
3. **時間管理**：調研應在寫作前完成，不要邊寫邊查打斷創作節奏
4. **結果存儲**：依上方「結果存放規範」分流存放，避免重複搜索
