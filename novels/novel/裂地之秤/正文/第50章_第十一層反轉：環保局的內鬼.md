# 第 50 章 - 第十一層反轉：環保局的內鬼

九月八日上午九點整，新北市政府行政大樓十一樓，環境保護局空品與噪音防制科中央機房外，拉起了一道刺眼的黃黑相間警用封鎖線。

機房厚重的防磁氣密門敞開著，十幾台二十四小時運轉的高密度伺服器機櫃正發出震耳欲聾的風扇呼嘯聲。冰冷的精密空調氣流在離地三十公分的防靜電高架地板下方瘋狂穿梭，激起一股冰冷而乾燥的臭氧微氣味。

方哲緯站在第四號核心數據機櫃前，身上的深灰風衣尚未褪去，金絲眼鏡後的雙眼透著通宵未眠的森寒。

在他的身側，沈巡雙手插在深藍色防風夾克口袋裡，整個人如同一尊佇立在風暴中央的黑色鐵塔。沈巡那雙布滿血絲的眼睛，正冷酷地鎖定在機櫃第三層那具被暴力拉出、導軌變形卡死的「大河之森專案即時採樣陣列主機」上。

主機面板上，原本應該恆亮綠燈的四顆 SAS 熱插拔硬碟槽位，此刻正空空如也，只剩下四個黑洞洞的卡槽。

旁邊的外接監控螢幕上，跳動著大片刺目的紅色報錯字元：

`Error 0x80070002: System Hardware Not Found`

`Log Stream PID_VOCs_20240828: NULL / Physical Sector Corrupted`

整整八天份、包含陳伯命案案發當天清晨五點到八點之間，大河之森現場所有手持式 PID（光離子化偵測器）所測得的三氯乙烯（TCE）原始濃度日誌，在資料庫中全數呈現「實體損毀無法讀取」的空白斷層！

「沈隊長，方律師，大家先冷靜一下。」

新北市政府政風處第二組組長許長青乾咳了一聲，推了推金邊眼鏡，手裡拿著一份剛剛列印出來的《重大資訊設備異常初步鑑定報告》，試圖擋在機櫃與兩人之間：

「資訊中心工程師剛才做了初步檢測，這台伺服器是因為昨晚機房天花板冷凝水管微量滲漏，水滴滲入陣列卡引發短路，硬碟控制晶片自我燒毀……純粹是一起不可抗力的工安與設備老舊事故。政風處已經依規定通報副市長室，我們會儘快協調原廠進行資料恢復，真的不需要刑大重案組介入——」

「冷凝水管滲漏？」

沈巡從牙縫間擠出一聲令人脊背發寒的冷笑。

他猛地跨前一步，右手自夾克內袋中掏出一張用透明證物袋封存、邊角焦黑微捲的熱感傳真紙，「啪」的一聲，重重拍在許長青面前的機櫃鋼板上！

金屬碰撞發出炸雷般的脆響！

「許組長，睜大你的狗眼看清楚！」

沈巡指著證物袋頂端那行黑色的時間戳記，聲音低沉得像是在砂石地上拖拉重物：「昨天清晨五點二十分，林口大通土資場被我抄底前四十分鐘，新北市府大樓內線分機發出的熱感傳真！『風、雨、欲、來』四個字，墨水都還沒乾！你現在跟我講昨晚冷凝水漏水剛好把四顆硬碟拔走？你當老子穿了十八年刑警背心，是在菜市場切豬肉的？！」

許長青臉色劇變，額頭上的冷汗瞬間涔涔落下，身子不由自主地往後退了半步，卻正好撞在身後方哲緯挺括如鐵壁的風衣前襟上。

「許組長。」

方哲緯的聲音在此刻如同冰水澆在滾燙的鐵板上，不帶一絲火氣，卻字字致命。

他優雅地自隨身公事包內抽出一台平版電腦，指尖輕輕劃開螢幕，展示出一份新北市人事處的公務員任免考績清冊，以及一份台灣商業司的公司登記公示資訊：

「依《公職人員財產申報法》第七條，以及行政院《廉政倫理規範》第三點規定，公務員配偶於利害關係人之營利事業任職並受領報酬者，應主動向服務機關政風機構報備。」

方哲緯轉過身，目光穿透機房透明的隔音玻璃，精準地定格在門外走廊邊緣、正抓著一條毛巾瘋狂擦汗的年輕公務員身上。

「陳彥銘先生。」

方哲緯聲音不大，但在安靜的長廊與機房內卻清晰得宛如審判：「新北市環保局土水科三等環境稽查員，大河之森命案首日手持式 PID 現場採樣的唯一登錄人兼數據上傳員。」

走廊上的陳彥銘猛地一抖，手裡的毛巾啪嗒一聲掉在地上。

方哲緯將平版電腦轉向許長青與陳彥銘，指針點在螢幕上的兩份契約文件上：

「三個月前，陳稽查員剛剛在新莊副都心購置了一棟兩千四百萬的新婚住宅，每月房貸負擔八萬兩千元。而在陳員購屋後一週，陳員的新婚妻子林雅婷女士，突然受聘於一家名為『富通綠色物流開發股份有限公司』的企業，出任『海外碳權數據審查專員』，合約載明年薪新台幣……三百二十萬元整。」

方哲緯收起平版，抬起那雙清冷深邃的眸子，冷冷逼視著雙腿發軟的陳彥銘：

「富通綠色物流的最大法人股東，持股百分之七十，名字叫作『大通環保工程股份有限公司』——負責人：蔡義宏。而林雅婷女士在過去三個月內，打卡記錄為零，出入境記錄為零，唯一的工作成果，就是每個月五號，從蔡義宏的私人帳戶，收受二十六萬六千元的轉帳顧問費。」

「嗡——」

整間機房只剩下伺服器風扇冰冷的呼嘯聲。

第十一層反轉，在方哲緯平靜如水的法規條文下，徹底被撕開了血淋淋的真相。

市府官方的環境監測防線，從頭到尾都沒有失靈！

手持式光離子化偵測器沒有故障，中央伺服器的晶片也沒有被冷凝水燒毀！

蔡義宏早在三個月前、在大河之森都更案剛剛通過示範容積評定的那一刻，就已經動用了境外基金的洗錢網絡，以一份完全合法的「企業顧問高薪聘任合約」，精準買通了這名在一線負責採樣與數據登錄的基層稽查員！

「三百二十萬……」

沈巡雙拳緊攥，骨節發出可怕的咯咯聲，一步步朝著癱軟在門框邊的陳彥銘走去。

沈巡的眼神像是要吃人，十八年刑警生涯的狂怒在這一秒徹底噴發：「我哥當年被撞死在疏洪道，全家拿不到一毛錢！陳伯在冰凍炭盆旁邊死得硬邦邦，就是為了砸碎這座天平！你拿著黑道三百二十萬的買命錢，動動手指把硬碟拔掉……你知不知道捷運新莊線菜寮段每天沉陷兩毫米，地底下埋著幾萬人的命？！」

「撲通！」

陳彥銘再也承受不住這股如泰山壓頂般的恐怖威壓，雙膝重重砸在防靜電地板上，抱頭痛哭：

「沈隊！方特助！饒了我……我不是故意的！我真的不是故意的！」

陳彥銘涕淚橫流，雙手死死抓著沈巡的褲腳：「是蔡義宏！前天半夜蔡義宏親自打電話給我，說外國人逼他把市府伺服器拔掉……他說只要我把硬碟拔出來，他就把富通物流的股權過戶百分之五給我老婆！但蔡義宏在電話裡交代我，硬碟千萬不能砸碎，他說那是防著外國人滅口的保命底牌，讓我拔下來之後藏在機房裡……不要交給任何人！」

沈巡猛地彎腰，單手揪住陳彥銘的衣領，將他整個人生生提了起來：

「硬碟在哪裡？！」

「在……在茶水間！」陳彥銘崩潰大喊，手指指向走廊盡頭：「在茶水間天花板……第三具消防栓軟管後面的維修孔夾層裡！我用防靜電氣泡袋包好了……四顆硬碟全部都在裡面！」

沈巡鬆開手，陳彥銘爛泥般摔在地上。

小陸和兩名刑警不用沈巡吩咐，早已如離弦之箭般衝向走廊盡頭的茶水間。

三十秒後。

小陸雙手捧著一隻沉甸甸、用黑色工業膠帶密封的防靜電氣泡袋，快步跑回機房，臉上滿是狂喜：「沈隊！起獲了！四顆原廠 SAS 硬碟，序號跟機櫃完全吻合，封籤完好！」

許長青站在一旁，面色灰敗如死灰，雙手無力地垂在身側，再也說不出一句阻攔的話。

方哲緯自風衣內袋掏出一具隨身攜帶的磁吸防寫外接硬碟座（Write-Blocker），插上離線 ThinkPad 的 USB 接口，隨後接過小陸遞來的第一顆主硬碟，熟練地壓入槽位。

電源開啟，硬碟馬達發出平穩而清脆的旋轉聲。

終端機螢幕瞬間跳出一條綠色的掛載進度。

方哲緯敲下一串 SQL 查詢指令，調出二〇二四年八月二十八日清晨五點至八點的歷史日誌庫存。

螢幕中央，一條原本被刻意抹殺的曲線，在跳動的代碼中，宛如破土而出的巨蟒，轟然顯露！

`[05:12:33 AM] Sensor_ID: PID-3000-A04`

`Location: Sanchong_Chongxin_Plot_01 (Chen's Residence)`

`VOCs_TCE_Concentration: 128.4 ppm (CRITICAL DANGER: EXCEEDS STATUTORY LIMIT BY 25.6x)`

`Status: RED ALERT TRIGGERED`

一百二十八點四個 ppm！

法定標準值的二十五點六倍！

鐵證如山！

這份被蔡義宏以三百二十萬高薪企圖永久埋葬的原始日誌，終於在這一秒，重見天日！

沈巡凝視著螢幕上那條高高昂起的猩紅曲線，右手緩緩自口袋中掏出一副泛著冷光的警用制式鋼銬，隨手扔在失魂落魄的陳彥銘胸口：

「小陸，銬上。依《貪污治罪條例》違背職務收受賄賂罪，移送新北地檢署收押禁見！」

「是！」兩名刑警上前，冰冷的手銬瞬間鎖死了陳彥銘顫抖的手腕。

機房內，刺耳的風扇轟鳴依然在持續，但那股籠罩在眾人心頭長達數日的窒息陰霾，卻在這一刻被撕開了一道巨大的口子。

方哲緯按停了秒錶，將日誌數據匯出至加密隨身碟，妥帖收好。

他轉過身，與沈巡並肩走出機房，邁入十一樓長廊清晨燦爛的陽光之中。

沈巡停下腳步，嘴裡嚼著那顆已然失去甜味的薄荷糖，偏頭看向身旁這位冷酷得像是一具精密儀器的法務長：

「方特助，硬碟拿到了。蔡義宏的底牌全漏了，市府的防火牆也塌了……接下來，你打算怎麼做？」

方哲緯推了推金絲眼鏡，轉頭迎向沈巡布滿血絲卻如刀鋒般銳利的目光，嘴角勾起一抹極淡、卻深不見底的冷冽弧度：

「接下來，公股銀行的八十五億聯貸風控顧問……陳浩然先生，今天下午該進場了。」

說完，方哲緯邁開長腿，踏著長廊上被陽光拉得筆直的陰影，大步朝著電梯間走去。

身後，沈巡右手摸了摸夾克暗袋裡那根始終未曾點燃的長壽菸，眼神中的凶芒宛如穿透晨霧的破甲鋼錐，與方哲緯的腳步聲一道，徹底拉開了第三卷金融與資本絞殺的終極序幕。
