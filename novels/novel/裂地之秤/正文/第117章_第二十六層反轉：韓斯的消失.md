# 第 117 章 - 第二十六層反轉：韓斯的消失

十月十二日，Day 56 下午十五點整。

新北市三重區雙鳳街，雙鳳宮後殿香客大樓二樓，主委專用套房。

房間裡沒有開燈，兩扇加裝了隔音海綿的厚重遮光天鵝絨窗簾拉得嚴絲合縫，將午後刺眼的秋陽完全阻隔在室外。

昏暗的屋內，空氣濃稠悶熱得令人作嘔，混雜著神龕前沉香燃盡的焦苦味、吃剩的油膩排骨便當酸氣，以及人體在極度恐懼下分泌出的冷汗酸臭。黑面三媽神龕下方，兩盞暗紅色的電燭燈散發著微弱而猩紅的光暈，映照在跪在地板上的那個男人臉上。

大通環保工程負責人、雙鳳宮新任主委——阿標。

阿標赤著雙腳，身上那件洗得發黃的白背心被冷汗浸透，緊緊貼在他乾瘦排骨般的胸膛上。他的右手無名指原本戴著一枚從蔡義宏手指上扒下來的黑膽石金戒指，此刻戒指已經被他緊張地啃咬得佈滿了深陷的牙印。

在他的面前，擺著一張從日曆紙背面撕下來的泛黃紙條。

紙條上用藍色圓珠筆寫著一串長達十四位的國際衛星電話號碼，後面標註著一行時間：

【10/12 15:00 · 尾款四千五百萬電匯確認碼：LUX-TR-8821】

在紙條旁邊，放著一部沉重、包裹著軍綠色防摔橡膠套的瑞士原裝 Crypto-AG 加密衛星電話。

這是韓斯在蔡義宏命喪烏日的那天清晨，派人秘密送到雙鳳宮門口的終端設備。韓斯在最後一次通話裡用生硬的中文告訴過他：十月十二日下午三點整，只要宏岳的停工令不可逆轉，四千五百萬的海外清運補償與撤離廣東的漁船坐標，會準時在通話中交割。

阿標看著牆上那面老舊的石英鐘。

秒針「喀嗒、喀嗒」地跨過了十二點的刻度，時針與分針在「三」與「十二」的位置上嚴絲合縫地重合。

下午三點整。

阿標喉結上下滾動了一下，在神龕前重重磕了一個響頭，隨後顫抖著抓起了那部冰涼的衛星電話。

他伸出滿是污垢與老繭的食指，一個數字、一個數字地按下了那串十四位的國際號碼。

按下綠色撥號鍵的瞬間，阿標的整顆心臟猛地提到了嗓子眼。

他將聽筒死死貼在滿是黏汗的耳郭上。

沒有他預期中那種穿透大氣層的長途呼叫蜂鳴聲，也沒有數據流交握時那種清脆的電信雜音。

聽筒裡傳來的，是一道冰冷、清晰、帶著機械合成質感的英語女聲：

「We are sorry. The number you have dialed has been decommissioned and is no longer in service. Please check the number and dial again.」
（對不起。您所撥打的號碼已經退役銷毀，不再提供服務。請查證後再撥。）

緊接著，是一陣單調而漫長的忙音：

「嘟……嘟……嘟……」

阿標愣住了。

他的大腦一片空白，像是被重錘狠狠砸了一下，整個人呆滯地跪在原地。

「按錯了……肯定是按錯了……媽的，老子手抖按錯了……」

阿標自言自語地神經質喃喃著，胡亂用手背擦去眼眶上的冷汗。他趴在地上，眼睛湊近那張紙條，手指幾乎要把按鍵戳破，重新按下了那十四個數字。

「嘟……嘟……嘟……The number you have dialed has been decommissioned……」

第三次。

第四次。

第五次。

每一次，話筒裡傳來的都是那具毫無感情的機械女聲，像一道無形的鐵箍，將阿標的咽喉死死掐緊！

「操你媽！接電話啊！接電話啊韓斯！」

阿標終於崩潰了，他失控地對著話筒咆哮起來，聲音沙啞尖厲，在封閉的房間裡瘋狂迴盪。

他猛地將衛星電話摔在地上，手腳並用地爬到茶几前，一把掀開了那台連接著外接天線的 ThinkPad 筆記型電腦。

螢幕亮起刺目的白光。阿標用沾滿冷汗的手指狂敲鍵盤，登入他這半個月來每天接收指令的瑞士安全郵箱。

網頁加載的旋轉圖示轉了三圈，隨後彈出了一行黑底白字：

【HTTP 404: Mailbox Deleted by Administrator. All Associated Data Purged.】
（信箱已被管理員物理刪除，所有關聯數據已清空。）

阿標猛地抓碎了自己的頭髮。他不顧一切地打開 Telegram，點開了置頂的那個只有一個字母代碼「H」的對話視窗。

然而，映入眼簾的，不是以往那些冰冷的物流出庫指令，而是一片刺目的死寂——

原本戴著「盧森堡登山協會黃銅徽章」的頭像，已經徹底變成了一個毫無面孔的深灰色幽靈剪影。對話框最上方顯示著一行淺灰色的系統提示：

【Deleted Account】
（帳號已銷毀）

更讓阿標毛骨悚然的是，對話框裡過去所有的文字、語音、座標與定時照片，在這一刻全部消失得無影無蹤，只留下一行用紅色小字標註的系統日誌：

『This secret chat was destroyed by remote wipe command at 10/12 04:00 UTC.』
（此秘密對話已於格林威治時間凌晨四點被遠端抹除指令徹底銷毀。）

「跑了……」

阿標癱坐在冰涼的花崗石地板上，筆記型電腦的光芒照在他那張毫無血色的青灰面孔上，眼珠外凸，像是一具剛從淡水河裡撈上來的浮屍：

「他們跑了……韓斯那個雜種……他們全都跑了……」

【第二十六層反轉：外資離場收線】。

在宏岳這場橫跨五卷、捲入數百億資金的驚天殺局裡，外資從一開始就沒有打算在台灣留下任何活口與痕跡。

新加坡市場做空獲利的三百八十億新台幣，早在四十八小時前就已經全數換成美元，通過七層離岸信託的洗錢管道流向了列支敦斯登與開曼群島；市府的無限期停工令已經下達，宏岳綠色債券已經變成廢紙。外資的收割任務已經圓滿達成。

對於遠在蘇黎世的跨國操盤手而言，蔡義宏、阿標、大通環保那四十七輛土方砂石車，甚至是這座雙鳳宮裡供奉的黑面三媽，從頭到尾都只是一次性使用的白手套。

用完了，撕碎，扔進火盆裡化成灰燼。

阿標坐在地上，突然發瘋似地伸出雙手，一把抓起身旁那隻發臭的厚底登山鞋。

他用顫抖得如同風中落葉般的手指，瘋狂撕扯著鞋墊邊緣的縫線，將藏在鞋底防震海綿凹槽內的那枚黑色 MicroSD 記憶卡摳了出來。

指甲蓋大小的塑膠晶片被他死死攥在掌心裡，金屬接點刺破了他大拇指的皮膚，滲出一粒暗紅色的血珠。

這張卡裡，整整齊齊儲存著十三段音訊檔案。那是他瞞著蔡義宏、瞞著韓斯，偷偷用微型錄音模組錄下的通話記錄。

裡面有韓斯指令大通車隊運送 1.2 噸乾冰去陳伯靈堂的通話；有韓斯指示調包市府岩芯樣品的 GPS 坐標；還有蔡義宏被殺前三天，韓斯在電話裡逼蔡義宏交出海外洗錢帳號的冰冷聲紋。

半個月前，阿標把這張卡視為自己下半輩子最大的搖錢樹。他以為只要手握這張卡，韓斯就不得不給他四千五百萬，他就能像蔡義宏當年那樣，跑到廣東買洋房、開豪車。

但現在，韓斯消失了。

母基金撤退了，所有的境外伺服器全部格式化了。

這張卡在國際金融市場上，連一分錢的贖金都換不回來！

不僅如此——阿標猛地打了個寒戰，一股刺骨的寒意順著他的尾椎骨直衝天靈蓋。

蔡義宏是怎麼死的？

在台中烏日那間偏僻的鐵皮民宿裡，被兩名穿著黑色戰術服的外籍特工，硬生生按在浴缸邊緣，往頸動脈裡注射了四百單位的超短效胰島素，偽裝成低血糖休克溺斃！

外資不是不給錢，外資是只要平倉結束，就會把所有知道內幕的白手套，一個一個殺乾淨！

韓斯切斷了所有聯絡線，不是為了躲避他阿標，而是為了讓專業的清除小隊進場！

只要這張記憶卡還在他的手裡，只要他還活著，那些戴著盧森堡登山協會皮帶扣的殺手，隨時會像幽靈一樣破開雙鳳宮的大門，把他推進浴缸裡！

籌碼變成了催命符。

「吱——！」

就在這時，樓下雙鳳宮幽暗的廟埕外，突然傳來了一陣刺耳至極的輪胎煞車聲！

緊接著，是沉重的車門合攏聲，以及皮靴踩在碎石子地面上的沙沙腳步聲。

阿標嚇得發出一聲尖叫，整個人彈了起來。他瘋狂地四下張望，手忙腳亂地把那枚沾著血的 MicroSD 記憶卡塞進了自己嘴巴的下牙齦內側，用舌頭死死抵住。

他撲到神龕後方的暗門前，抓起車鑰匙與一把生鏽的折疊彈簧刀。

「不能留在這裡……不能去找外資……」

阿標滿臉淚水與鼻涕，眼神裡爆發出瀕死野獸般的瘋狂光芒：

「沈巡……對……沈巡！只有沈巡能保老子的命！」

暗門拉開，阿標像一隻驚弓之鳥，一頭扎進了通往後巷防汛堤防的狹窄消防通道中。
