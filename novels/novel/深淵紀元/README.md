# 《深淵紀元》（Abyss Epoch）目錄結構說明

本目錄為《深淵紀元》小說創作工作區，基於 `novel-memory` 與 `novel-worldbuilding` 體系構建。

## 目錄導覽
- `plan.md`：總控大綱（全書設定、故事梗概、分卷規劃、支線規劃）
- `設定/`：小說核心設定庫
  - `characters.md`：人物檔案
  - `world.md`：世界觀與力量體系規則
  - `foreshadowing.md`：伏筆台帳（動態追蹤唯一來源）
  - `timeline.md`：時間線規劃
  - `relations.md`：人物關係網絡
  - `story-so-far.md`：全書現況快照
- `正文/`：逐章小說正文
- `summary/`：逐章歷史摘要日誌
- `review/`：逐章質量審核報告（novel-review 產出）
- `research/`：專項調研筆記（novel-research 產出）
