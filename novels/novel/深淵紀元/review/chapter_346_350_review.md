## 二、維度八專項審查（語言、時代語境與認知隔離）

### 1. 認知隔離與時代語境
- **本組特色**：本組為全書最高潮的科技驚悚、資本反抗與歷史真相揭密章節。場景橫跨深淵主城安全區、外圍商道戰場、深空底層量子核心與現實高雄指揮要塞。
- **角色語境檢驗**：
  - 發狂的衛兵隊長：發狂囈語「頭好痛……你們的心臟都要停跳」，純粹狂暴神經混亂，無現代科學名詞干擾。
  - 死難者幽魂殘影：七歲女孩小雨「好冷……媽媽我的手動不了了……醫生叔叔不要扎針……我想回家」、老工友林叔「好想念高雄前鎮碼頭清晨的熱麵線……」，展現十年前高雄底層受害者的原生情感與記憶，情真意切，語境無比契合。
  - 柯景延、陳哲宇、沈墨與跨國公會高層：使用高科技生化、網路協定、現代特戰軍事用語，邏輯嚴密。

### 2. 繁體中文與台灣在地化用語校正
本批次全面清理殘留簡體詞與非在地化用語，主要替換成果如下：
- **核心科技與 IT 術語**：
  - 「超算 / 超算集群」統一修正為「超級電腦 / 超級電腦叢集」。
  - 「硅基芯片」修正為台灣標準「矽基晶片」；「芯片」修正為「晶片」。
  - 「納米」修正為「奈米」。
  - 「代碼 / 代碼流 / 源代碼 / 痛苦代碼 / 代碼暴雨」全面修正為「程式碼 / 程式碼流 / 原始碼 / 痛苦程式碼 / 程式碼暴雨」。
  - 「數據 / 數據流 / 數據深淵 / 數據爛泥」全面修正為「資料 / 資料流 / 資料深淵 / 資料爛泥」。
  - 「計算機程序 / 超級計算機」修正為「電腦程式 / 超級電腦」。
  - 「太字節」修正為「TB」；「字節碎片」修正為「位元組碎片」。
  - 「網絡數據包」修正為「網路資料封包」。
  - 「信號」修正為「訊號」；「坐標」修正為「座標」。
  - 「協議」修正為「協定」；「密鑰」修正為「金鑰」。
  - 「屏幕」修正為「螢幕」；「界面」修正為「介面」。
  - 「帶寬」修正為「頻寬」；「運營款項」修正為「營運款項」。
- **在地化生活與醫療用語**：
  - 「醫保費」修正為高雄在地「健保費」。
  - 「自費協議」修正為「自費協議書」。
  - 「千刀萬刮」修正正字為「千刀萬剮」。
  - 「碳化」修正為「炭化」；「咔噠」修正為「喀噠」；「布滿」修正為「佈滿」；「激活」修正為「啟動」；「數米 / 二十米 / 三米 / 五十米」修正為標準公制「公尺」。
