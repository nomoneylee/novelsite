# 第 315 章摘要

- **章節標題**：散人刺客組織「無赦閣」現身
- **所屬卷/支線**：第四卷 前哨篇 / S08（第 1/30 章，正式開闢）
- **主要登場人物**：柯景延（無溫）、沈墨（判官）
- **核心情節概要**：
  1. 柯景延走出萬毒窟抵達西域黑戈壁，感知到隘口處潛伏的頂尖散人刺客合圍。
  2. 全服第一散人刺客組織「無赦閣」閣主沈墨（判官）現身相邀，揭露歐美跨國公會在主城外圍無差別獵殺散人、封鎖卡拉贊前哨鑰匙碎片的暴行，提議奉柯景延為暗夜客座長老，聯手抗衡豪門。
  3. 柯景延一眼識破其依託神經毒素破盾的算盤，冷靜直指核心利益；沈墨坦誠私心，提出以全服七十二主城暗網情報庫與卡拉贊外圍牽制神聖十字主力為籌碼，換取神經毒素塗抹。
  4. 系統正式開啟陣營支線【S08：無赦閣的盟約】（第 1/30 章），柯景延提出「接我三招不死」的實力驗證要求，沈墨欣然應戰。
- **戰略資源與屬性變動**：
  - 解鎖【散人刺客地下暗網匿名頻道】訪問權限。
- **伏筆與因果關聯**：
  - 正式開闢第四卷重要陣營支線【S08：無赦閣的盟約】（第 1/30 章）。
