# 台灣在地語彙、兩岸用語對照與抗 AI 審核規範調研筆記 (research)

本筆記依據 `novel-research` 規範建立，直接響應 `novel-review`（維度 8 語言風物規範、維度 11 文風重複度、維度 13 抗 AI 腔調）與 `novel-prose`（語言一致性與抗 AI 說教腔）的嚴格審核標準。

全書所有章節正文執筆與審核，必須以此檔案為**語言審查基準**，嚴禁任何出戲簡體俚語、大陸流行網梗與 AI 模板套話。

## 1. 兩岸日常用語對照與絕對禁用詞庫

本作品時空設定為台灣中部（彰化田中、二水、南投集集、水里）與台北都會，全書對白、旁白與心流獨白嚴格採用**正統繁體中文與台灣在地語彙**。

### 核心禁忌與對照表（出現即判定為 🔴 審核違規）

| 大陸 / 簡體俚語 / 網梗（🔴 絕對禁用） | 台灣在地規範用語（✅ 正確用法） | 語境與小說運用範例 |
| :--- | :--- | :--- |
| **立馬** | 立刻、馬上、旋即、轉身就…… | 「他**立刻**縮回了手，把塑膠袋塞進懷裡。」 |
| **質量** | 品質、質素、質感（物理學「質量mass」除外） | 「這件起毛球的外套**品質**很差，但很保暖。」 |
| **給力** | 帶勁、爭氣、厲害、幫大忙 | 「阿達這次真的很**夠意思**。」 |
| **貓膩** | 蹊蹺、鬼、問題、不單純、手腳 | 「公文審查裡肯定有人**動了手腳**。」 |
| **套路** | 把戲、手段、花招、慣用招數 | 「少來這套**花招**，林予涵妳騙誰啊。」 |
| **視頻** | 影片、短影音、錄影 | 「許佩瑜用手機剪輯宣傳**影片**。」 |
| **打印** | 列印、印出來 | 「陳詠寧深夜在辦公室**列印**防災成果冊。」 |
| **硬盤 / U盤** | 硬碟 / 隨身碟 | 「把企劃案備份到**隨身碟**裡。」 |
| **軟件 / 硬件** | 軟體 / 硬體 | 「電腦**軟體**當機，存檔差點不見。」 |
| **忽悠** | 唬弄、拐騙、誆騙、瞎扯 | 「你少在那邊**唬弄**我，下個月要繳水電了。」 |
| **走心** | 用心、認真、放在心上 | 「那句話讓她真的**聽進心裡**了。」 |
| **吃瓜 / 老鐵 / 打call / 帶節奏** | 看熱鬧 / 兄弟 / 聲援 / 起鬨 | 嚴禁出現大陸網路流行梗。 |
| **塑料** | 塑膠 | 「便利商店的**塑膠提袋**發出窸窸窣窣的聲響。」 |
| **洗手間 / 衛生間** | 廁所、化妝室、便所（台語日常） | 「借一下車站**廁所**洗手。」 |

## 2. 鐵道、交通與生活場景專業語彙對照

全書以台鐵集集支線為實體骨架，涉及交通運轉與城鄉生活時，必須使用百分之百精確之台灣本土鐵道名詞：

| 非台灣鐵道 / 出戲用語（🔴 禁用） | 台灣鐵路與交通規範語彙（✅ 正確） | 備註與場景規範 |
| :--- | :--- | :--- |
| **站台** | **月台** | 絕不可寫「二水車站第二站台」，必須寫「第二月台 / 2B 月台」。 |
| **鐵軌（部分情境） / 道軌** | **鋼軌、鐵軌、軌道** | 專業運轉時用「鋼軌」，日常描寫用「鐵軌」。 |
| **綠皮車** | **柴油客車、慢車、普通車、冷氣柴客** | 集集線為 DR1000 冷氣柴客，非無空調綠皮車。 |
| **火車票 / 車票（劃位）** | **車票、感熱紙票根、儲值卡、悠遊卡** | 集集線為「全車自由座非對號」，無「劃位車票」。 |
| **地鐵** | **捷運** | 台北都會場景一律為「捷運（淡水信義線/板南線）」。 |
| **公交車 / 大巴** | **公車、客運、接駁車、台灣好行** | 詠寧搭乘的是「員林客運」或「南投客運」。 |
| **出租車 / 的士** | **計程車、小黃** | 車站前排班的是「排班計程車」。 |
| **乘務員 / 列檢** | **列車長、車長、查票員、站務員** | 「車長拿著打洞剪查票。」 |

## 3. 教育公職與偏鄉體制在地名詞庫

陳詠寧任教的偏鄉國小與台北私立名校，必須完全依照台灣教育部與各縣市教育局處之法規制度名詞：

| 規範專有名詞 | 具體情境與定義 |
| :--- | :--- |
| **代理教師** | 具備完整課務與導師責任，一年一聘（非短期代課幾天的「鐘點代課」）。 |
| **代課教師** | 按鐘點支薪之鐘點教師（日常對話中詠寧偶爾自嘲為「代課」，但正式公文為「代理教師」）。 |
| **教甄** | 公立國民小學教師聯合甄選（初試筆試、複試試教與口試、三折頁個人簡歷）。 |
| **學務處** | 國小負責學生事務之處室，下轄「訓育組/生教組」、「體育組」、「衛生組」。詠寧兼任訓導業務。 |
| **公文夾 / 成果冊** | 兩孔拱型資料夾、核銷發票黏存單、防汛疏散演練成果冊、督學視導督核單。 |
| **私立名校體系** | 台北薇閣中學（國中部/高中部）、董事會核備、公費出國留職停薪、夜間自習督導。 |

## 4. 抗 AI 高頻套語與生硬模板清單

AI 輔助小說創作最容易出現「詞彙貧乏、慣性套話、結尾畫句點」之嚴重毛病。依據 `novel-prose` 與 `novel-review` 規範，以下字詞列為**高頻監控黑名單**：

### 1. 情緒與神態套語（全書嚴格控管，單章嚴禁重複）
- 🔴 **情緒通用套話**：「不由自主」「一絲（一絲驚訝/一絲苦澀/一絲欣慰）」「複雜的情緒」「心中湧起一股」「說不出的滋味」
- 🔴 **神態臉譜動作**：「眼中閃過一絲」「嘴角勾起一抹」「深吸一口氣」「握緊了拳頭」「瞳孔微縮」「嘴角微揚」
- ✅ **替代方案（以真實物理反應取代）**：
  - 改用具體動作：手指將工裝口袋裡的硬幣翻了個面、指甲刮著磨損的錶蓋、把茶葉蛋殼按在窗台上壓裂、後頸皮膚發癢抓了一下。
  - 改用環境對比：柴油客車氣軔洩氣的尖銳嘶嘶聲、水圳裡奔流而過的混濁急流。

### 2. 章末「畫句點式」收尾套語（章節最後三段絕對禁止）
AI 最喜歡在章節末尾以大團圓、哲理昇華或抒情空鏡強行做總結，**破壞讀者的翻頁慾望**。以下收束語出現在結尾即判定違規：
- 🔴 **絕對禁止的結尾套話**：
  - 「陽光灑進……」「夕陽將天空染成一片血紅……」「夜色漸濃……」「老街的風輕輕吹過……」
  - 「帶走了……帶來了……」「就在……之中，悄然展開/融化……」
  - 「像是一首……」「默默守護著這座小鎮」「萬家燈火點亮」「人間煙火氣」
  - 「車廂緩緩駛向遠方，而屬於他們的故事，才剛剛開始……」
- ✅ **正確的章末收筆技法（自然斷點法）**：
  - 在**動作中途停筆**：陳詠寧把蛋黃塞進嘴裡，頭撞上車窗，閉上眼睛。
  - 在**對話的懸念處停筆**：林予涵握著冰冷的鐵盒，門外傳來急促的剎車聲。
  - 在**突發事故或時空節點停筆**：廣播聲響起，列車在黑暗的隧道口猛烈震盪了一下。

## 5. 抗 AI 道德說教與心理總結審查（維度 13 核心）

### 核心原則：角色不替作者反省，情節不替讀者總結
1. **拒絕事後心理反思**：
   - 當林予涵因為自卑與貧窮而選擇放手（第 25 章消音告白）時，嚴禁 AI 慣性加入：「他知道自己很懦弱，但在殘酷的現實面前，這或許是給她最好的溫柔……」這種自我開脫的雞湯。
   - 讓他直接閉嘴、微笑、轉身走進反向慢車。把痛楚留給讀者，不要替讀者擦眼淚。
2. **拒絕居高臨下的道德審判**：
   - 描寫長兄陳家明賭博欠債、母親軟弱包庇時，不加以倫理說教，只白描沾滿麵粉的圍裙、催繳單上的印泥紅印、校門口黑衣人嘴裡的檳榔渣。
3. **拒絕過度提煉主旨**：
   - 全書的核心意象（靠窗與走道、停在 21:43 的手錶、感熱紙票根）由讀者在行文中自然體會，角色和旁白絕不自我點題「這就像我們的人生一樣……」。
