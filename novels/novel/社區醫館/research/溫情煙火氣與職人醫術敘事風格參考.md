# 溫情煙火氣與職人醫術敘事風格參考

## 1. 定位與簡介

本文件為《社區醫館》正文寫作（配合 `novel-prose` 技能）提供文字風格、語言氣韻、醫術描寫視覺化與萬字長章節 Pacing 之範本指南。全書旨在呈現「溫暖、詼諧、無負面情緒、充滿台灣在地煙火氣」之職人成長故事。

## 2. 台味煙火氣對話節奏與語言風格範本

### 2.1 對話原則
- **自然流暢而不俗套**：採用台灣在地生活用語（客家國語、閩南語語尾助詞如「啦」、「齁」、「咩」、「捏」），但嚴禁過度堆砌俚語造成閱讀障礙。
- **句式錯落**：陸遠語速快且愛用反問句；張伯大聲老派；廖阿姨熱情如火連珠砲；蔡志豪碎念焦慮；林品妤簡潔精準。

### 2.2 對話範本：老街榕樹下的喜劇拉鋸
> 張伯一啪重重把黑子扣在棋盤上，氣得鬍子抖動：「陸遠！你這囡仔又偷吃我的包！你這算哪門子中醫師？看診不專心，偷下棋倒是快得很齁！」
> 
> 陸遠笑嘻嘻地端起保溫杯喝了一口降壓茶，悠悠推回一顆紅車：「張伯，棋能輸，氣不能急。你看看你這血壓，脖子後面筋都硬得像老竹竿了。來，先把這杯清心茶喝了，不然等一下輸給李伯，你又要怪我的茶沒效。」
> 
> 廖阿姨從旁邊提著剛買的生鮮水果經過，嗓門立刻拉高八度：「哎呀張哥！你就聽陸醫師的話啦！人家陸醫師現在是在救你的命捏！對了陸遠啊，阿姨舞蹈隊那個小陳的表妹，台北剛回來的，人漂亮又孝順，要不要阿姨幫你約時間喝個茶？」

## 3. 中醫醫術與感官描述視覺化範本

### 3.1 四診透視之視覺化譬喻
不要只寫「系統顯示張伯高血壓」，要用生動的身體感官與自然譬喻：
> 陸遠伸出三指輕扣在張伯的寸口脈上。指尖下傳來的不是平順流動的氣血，而像是一條在暴雨後急促抽動的河道。河床底部積壓著厚厚的淤泥（痰濕），而水流卻被陡峭的山壁限制（肝陽上亢），每一次心搏都在撞擊著脆弱的管壁。
> 
> 在【四診透視】的微觀感官中，張伯後頸風池穴附近的微血管如同緊繃過度的弓弦，呈現出一片微紅的鬱熱光暈。

### 3.2 煎藥與茶香感官描述
> 砂鍋裡的水漸漸沸騰，夏枯草與野菊花的苦甜香氣隨著白色的蒸汽蒸騰而起，混雜著決明子微焙過後的焦香。那不是西藥房裡冷冰冰的消毒水味道，而是一種帶著土地溫度的草木芳香。熱氣氤氳中，整間舊木屋醫館似乎都沉浸在一種讓人神清氣爽的安心氛圍裡。

## 4. 喜劇 humor 與溫情 tear-jerker 轉換筆法

```
情感起伏曲線：
[日常笑鬧/奧客反殺 (Humor)] ───► [醫學/法律硬核衝突 (Tension)] ───► [溫情化解/街坊互助 (Catharsis)] ───► [章末懸念 (Hook)]
```

### 4.1 轉換技巧
- **奧客反殺**：以毒舌與幽默反轉偏見（如奧客嫌茶貴，陸遠直接給他開一味苦煎藥，讓他「花錢買罪受」卻偏偏病好了，不得不提著水果來謝恩）。
- **深層情感**：當寫到育幼院孩子（如許小糖）深夜抱著舊洋娃娃想媽媽，或是陳院長偷偷用膏藥貼著發炎腰椎時，文字要瞬間收斂，轉為極度細膩、安靜而溫柔的第三人稱限制視角。
