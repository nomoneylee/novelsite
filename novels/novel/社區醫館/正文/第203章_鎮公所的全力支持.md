# 第 203 章 - 鎮公所的全力支持

上午十一點，青海鎮老街活動中心東側，兩扇沉重的老香杉木門在刺耳的軸承轉動聲中被推了開來。

塵封已久的光線透過高處的氣窗灑入室內，這座早年由花蓮農會作為儲穀與農機調度用的舊倉庫，空間挑高足有五米，粗壯的紅檜木梁柱結實完好，近百坪的水泥地面平整寬闊。儘管空氣中還殘留著少許陳年穀物的微燥氣息，但通風良好，夏無酷暑、冬無陰風，是老街一帶少見的寬敞室內空間。

青海鎮鎮長周國祥穿著一件淺藍色短袖公務襯衫，頭戴一頂遮陽便帽，身旁跟著手提公事包、滿頭大汗的張秘書。

「陸大夫、林律師，你們看這地方怎麼樣？」周鎮長雙手叉腰環視了一圈，爽朗的笑聲在空曠的倉庫裡嗡嗡迴盪，「自從前年農會新大樓落成後，這間東廂房就一直閒置著。鎮公所每個月還要撥預算請人來除草清蜘蛛網，要是交給你們醫館打造成全鎮第一處『長者健康休息站』，這叫活化公有資產，對老街、對全鎮都是天大的好事！」

張秘書連忙從公事包裡掏出一疊蓋好大印的契約草案，遞到林品妤面前，一邊擦汗一邊笑著補充：「林律師，鎮長昨晚親自向縣政府社會處與衛生局專案報告過了。這處空間免收十年租金，水電由鎮公所全額補助，長照 C 級巷弄站的正式核定牌照，下週二前縣府特派員就會親自送來！」

林品妤接過公文，目光飛快地掃過上面的條款細項。

作為台北頂級事務所合夥人，她對公產撥用合約向來嚴苛，但眼前的這份契約寫得極其公允周延，甚至主動將「青海偏鄉長照信託專款」的自主營運權與修繕監管權完整保障。

林品妤合上公文，看向周鎮長，語氣中帶著真誠的敬意：「周鎮長、張秘書，感謝鎮公所的全力支持。有了這份正式公文，諾華康信託補償專款的首期三百萬修繕與設備基金，今天下午就能完成撥款程序。」

「哎，林律師千萬別客氣！」周鎮長擺了擺手，轉頭望向身旁的陸遠，神色變得格外認真，「當初張秘書痛風急性發作，痛得差點在辦公室地上打滾，是陸大夫一杯藥茶、幾針下去當場止痛救命；前陣子山區青崖部落的水源中毒危機，要不是陸大夫親自進山採藥施針、林律師在法庭上把那些外國藥企打得落花流水，我們青海鎮現在還不知道要亂成什麼樣子！身為一鎮之長，為百姓做事的人，鎮公所要是不全力挺到底，我走在老街都要被鄉親戳脊樑骨！」

陸遠笑著拱了拱手：「鎮長言重了。有了這處據點，以後老街的長輩早起散步、買菜回來，隨時都能進來坐坐，喝杯熱茶、量個血壓、按按穴道，這才是社區醫館真正該有的樣子。」

「行！就照陸大夫的意思辦！」蔡志豪早就在倉庫各個角落拉著皮尺跑了三圈，嘴裡叼著鉛筆，手裡的筆記本上已經畫滿了密密麻麻的動線草圖。

蔡志豪快步跑回眾人身旁，指著草圖劈啪比劃起來：「門口這個二十公分的落差，今天下午工程隊進場直接澆灌一條一米五寬的無障礙防滑斜坡，方便推輪椅與坐電動代步車的阿公阿婆進出。進門左側是接待與電子血壓量測站；正中央擺四張香杉長桌作為下棋與茶飲休憩區；右側隔出三間半開放式的『艾灸溫燻與經絡理氣室』；後方靠窗處鋪設三十坪的防跌軟墊，給廖阿姨的志工隊帶長輩做經絡伸展操！」

「這個規劃好！」張秘書聽得連連點頭，「採光通風完全沒浪費，連安全防跌都考慮到了！」

話音未落，門外突然傳來一陣熱鬧非凡的腳步聲與鐵桶碰撞聲。

只見廖阿姨領著十二位身穿紅背心的志工隊員，人手一把掃帚、拖把與水桶，精神抖擻地湧進了大門口。

「鎮長好！張秘書好！」廖阿姨一進門就看見了周鎮長，大嗓門震得屋頂梁柱彷彿都在微微發顫，「我們在醫館剛培訓完，聽說鎮公所把東廂房點交給我們了，姐妹們立刻把家裡的掃帚水桶全扛了過來！今天不把這間屋子擦得能照出人影，我們午飯都不吃了！」

「哎喲，廖大姊，你們這行動力也太驚人了！」周鎮長笑得合不攏嘴。

志工阿姨們二話不說，立刻分工合作。接水的接水、掃地的掃地、擦窗戶的擦窗戶，原本略顯沉寂的舊倉庫瞬間被歡快的笑語與勞動的煙火氣息徹底點燃。

這時，張伯和李伯背著手，趿拉著拖鞋晃晃悠悠地從後院的小巷子繞了過來。

張伯手裡搖著摺扇，探頭探腦地在大門口打量了一圈，邁著四方步踱到陸遠身旁，用扇柄敲了敲旁邊一堵斑駁的紅磚隔牆。

「陸仔，這隔牆後面就是我們棋藝室的後院天井吧？」張伯挑著眉毛問道。

「是啊張伯，天井連著棋藝室的小茶水間。」陸遠點頭。

張伯用力敲了敲摺扇，一副指點江山的派頭：「那還等什麼！叫泥水匠直接在這邊牆上砸開一扇兩米寬的木拱門！老子以後在棋藝室下棋下渴了，一步就能跨過來喝茶量血壓，省得大熱天的還要繞出老街大馬路曬太陽！」

「張大哥，你這叫公器私用！」廖阿姨正提著水桶路過，忍不住笑著啐了他一口。

「什麼公器私用！」張伯眼睛一瞪，嘴硬地反駁道，「老街長照長照，棋藝室那些老頭子哪一個不是七老八十？把門打通了，下棋跟健康檢查合在一起，這叫一站式服務！周鎮長，你說我說得對不對？」

周鎮長大笑著拍了拍張伯的肩膀：「張老哥說得太對了！打通！這扇拱門的敲牆預算，算在鎮公所頭上！」

眾人一陣開懷大笑，大堂裡的氣氛熱烈無比。

陸遠走到倉庫中央，環視著整座建築的木石結構。

晉升至 Lv.4 宗師級的【百草萃煉】與全域被動「全域健康氣場」自然運轉，陸遠能敏銳地感知到這座舊空間內的氣流動向與微氣候特徵。高挑的檜木屋架極具吸濕調溫能力，但後側背陰處略顯陰涼。

陸遠從隨身藥箱裡取出兩包用艾葉、石菖蒲、蒼朮與佩蘭配製的天然中藥草驅穢醒腦散，遞給正在指揮清掃的廖阿姨：「廖阿姨，等地拖乾了，把這兩包藥草掛在後側通風口。艾草蒼朮能燥濕避穢，石菖蒲能醒腦開竅。長輩進來坐久了，呼吸順暢，心情自然好。」

「好嘞！還是陸大夫想得周到！」廖阿姨連忙小心翼翼地接過藥包。

正午十二點，整座舊倉庫已被志工阿姨們合力打掃得窗明几淨、地面透亮，檜木的淡淡清香與中藥草的芬芳交織在空氣中，令人神清氣爽。

張秘書將點交確認書工整地攤在長桌上，周鎮長率先簽下了名字，隨後林品妤代表基金會簽署了接收文件。

周鎮長鄭重地將一串黃銅大門鑰匙交到陸遠手中，緊緊握了握他的手：「陸大夫，青海鎮第一處長照站，今天正式交給醫館了！」

「請鎮長和鄉親放心。」陸遠接過沉甸甸的鑰匙，眼神堅定。

這時，站在門外的蔡志豪手機突然急促地響了起來。

蔡志豪接起電話聽了幾句，眼睛猛地一亮，快步衝進大門對著陸遠和林品妤揮舞著手臂：「大姊！陸遠！台北年會主辦方的確認函剛發到信箱了！梁崇明理事長把主會場特別演講的時間定在週三上午十點半！另外，高鐵商務艙車票和我們生技展位的十個宣傳展架，剛才全部確認排期完畢！」

林品妤收好合約文件，轉頭看向陸遠，清冷的眸子裡透出一抹自信：「後方長照站的硬體改造這週會全速推進。下週三，該輪到我們去台北主會場，讓全台灣的醫學界看一看青海醫館的真本事了。」
