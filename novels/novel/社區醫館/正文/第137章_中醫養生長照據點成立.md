# 第 137 章 - 中醫養生長照據點成立

二樓木桌上的手機劇烈震動著。畫面上跳動的台北區域號碼下面，緊接著顯示出一串熟記於心的後半段數字——那不是外地陌生人，而是鎮公所張秘書去台北衛生福利部參加偏鄉長照會報時使用的公務隨身機。

陸遠按下接聽，還沒開口，電話那頭就傳來張秘書興奮得有些沙啞的急促聲音：

「小陸！通過了！縣政府衛生局跟社會局剛剛聯合核發公文了！我們申報的『青海鎮第一 C 級巷弄長照站』跟中醫體質調理試辦計畫，正式拿到了全額補助批文！」

張秘書在電話那頭拍著胸脯喘氣，背景還隱約傳來台北平交道與車水馬龍的噪音：「我今天跟處長在協調會上據理力爭，拿你們育幼院跟醫館的長者調理紀錄當鐵證，硬是把這套長照柑仔店的牌子跟衛福部偏鄉整體照顧計畫補助金給爭取下來了！後天週一上午九點，我親自帶辦事員過去醫館掛牌！你記得把那個太衝穴跟和胃飲的宣傳單準備好啊！」

陸遠靠在沉香木書桌的椅背上，嘴邊帶著一抹從容的笑意，語氣卻依舊不緊不慢：「張秘書，大半夜十一點半，你這心率聽起來少說一百一。台北冷空氣大，你那痛風才剛好，就不怕夜宵喝了啤酒讓尿酸又飆起來？」

「飆什麼飆！這可是我們青海鎮社區醫療的大事！」張秘書大笑著，「對了，我剛才跟林品妤律師通了電話，她說法律顧問合約跟地政報備全處理好了。週一見！」

掛斷電話，陸遠看著窗外安靜的老街，把剛才跟孫思邈論道獲得的羊皮卷感悟默默收在隨身筆記本裡。

週一清晨，雨後的花東縱谷徹底放晴。台 9 線兩旁的稻田散發著潮濕的泥土香氣與秧苗青草香，青海鎮老街尾端的大榕樹下早早就擠滿了歡聲笑語。

老街尾的雙層舊木造藥膳房門口，張伯穿著那件壓箱底的深藍色短袖襯衫，手裡搖著摺扇，正跟棋藝室的李伯搶著指揮排隊位置。廖阿姨帶領著社區舞蹈隊的媽媽們，捧著剛蒸好的紅豆草仔粿與保溫壺，把醫館門口張羅得像要辦流水席喜事一樣。安康育幼院的陳院長也搬出了兩張長條木桌，擺在醫館前院供長輩歇腳。

「大家讓讓！張秘書拿牌子過來了！」

鎮公所的公務車停在老街口，張秘書穿著西裝背心，與兩位年輕辦事員小心翼翼地抬著一塊以厚重樟木雕刻的木匾走下車。木匾上用朱紅大字精細刻著：【青海鎮第一 C 級巷弄長照站·中醫養生據點】。

「小陸，這牌子掛在『懸壺濟世』木匾下面，剛好一文一武，保我們老街長輩活到一百歲！」張秘書接過阿山哥遞來的螺絲起子，親自站上梯子，把木匾穩穩鎖在舊木造藥膳房的門楣上方。

街坊們爆發出一陣熱烈的掌聲。許小糖穿著迷你版的小小醫師袍，胸前掛著她的榮譽櫃檯證件，啪嗒啪嗒跑上前去，給張秘書遞上了一杯溫熱的柴胡理氣茶。

「張叔叔辛苦了！陸遠哥哥說熬夜跑公文最傷肝氣，喝這個可以降血壓喔！」小糖天真地笑道。

張秘書大口喝下茶飲，擦了擦額頭上的汗水，笑得合不攏嘴：「還是小糖懂事！比你陸遠哥哥嘴巴甜多了！」

掛牌儀式結束，醫館看診室與後院長廊正式開啟了 C 級據點的首次免費體質篩檢與共餐服務。蔡志豪也特地從青海生技廠房派車送來了兩大箱剛封裝完成的試飲茶包，做為長照據點的開張禮。

陸遠坐在主診位上，開啟【四診透視】與【百草萃煉】，為前來排隊的老人家逐一進行體質辨識與健康檔案建檔。

張伯第一個坐在診桌前，把手腕往脈枕上一搭，眼睛直視著陸遠：「小陸，先說好，我今天可是代表長照據點第一號學員來受檢的，脈象要是好得很，你得請我喝兩包理氣茶。」

陸遠食指與中指輕輕扣在張伯的寸口脈上，【四診透視】的微光在眼底流轉，瞬間勾勒出張伯體內的氣血走勢——肝陽上亢的火氣比上週減了三分，但腰腎脈氣仍帶有些許冬季留下的虛寒。

「張伯，脈象比上個月平穩不少，不過平時少喝兩口高粱，太衝穴的壓痛感還能再少一半。」陸遠拿起毛筆，在長照據點的專用紀錄簿上寫下處方，「配伍改用夏枯草五分、野菊花三分、決明子一錢，每週一三五來據點喝一碗溫服。」

「算你小子看得準！」張伯滿意地收回手，搖著摺扇走到後院去聽長照衛教宣導。

後院的長廊下，「老幼共融」的溫馨場面正在自然展開。安康育幼院的阿寬和小芸等孩子們，在許小糖的帶領下，正給圍坐成一圈的長輩們遞上按壓穴位的說明卡片。

「李爺爺，按這裡，這是足三里喔！陸遠哥哥說多按這裡，脾胃就會變好，走路就不會膝蓋酸軟了！」小糖拿著小木棒，認真地在李伯的膝蓋下方三寸外側比劃著。

李伯揉了揉有些僵硬的關節，笑著拍手：「好好好，小糖教得好！爺爺今天中午多吃一碗共餐便當！」

廖阿姨在廚房與志工媽媽們合力烹煮著由陸遠開立的「健脾和胃山藥枸杞粥」，濃郁的草藥香味混著新鮮台梗九號米的香氣，在整個舊木屋裡飄散開來。

張秘書拿著長照評鑑紀錄表，隨手接過一碗熱粥，一邊喝一邊翻看著陸遠寫得清清楚楚的幾十份老人家體質檔案，驚嘆道：

「小陸，你這套『中醫體質分型加長照共餐』的模式，比縣城那些大醫院搞的純西醫檢查實在太多了！老人家來這裡有的喝茶、有的聊天、有的做穴位按壓與草藥推拿，簡直就是老街的養生柑仔店啊！」

「長照據點不是病院。」陸遠一邊替隔壁鄰居廖阿姨量血壓，一邊淡淡答道，「老人家怕的不是生病，是怕自己變成廢人沒人理。讓他們天天有目標出門、有朋友說話、有溫茶喝，病自然就少了一半。」

這時，醫館門口忽然傳來一陣急促的雨鞋踏地聲。

阿山哥穿著那雙沾滿後山梯田黑泥的雨鞋，手中緊緊捧著一個木盒，頭上冒著熱氣跑了進來，在看診室門口急停下腳步，連身上的泥水都沒顧得上擦。

「陸遠……」阿山哥聲音有些發緊，胸口劇烈起伏著，把手中的木盒遞了過來。

陸遠站起身來，接過木盒打開蓋子。木盒裡的麥飯石培養土中，一株葉脈呈現亮金色紋路、嫩綠欲滴的草藥幼苗正靜靜矗立著，在陽光下泛著一層淡金色的光暈。
