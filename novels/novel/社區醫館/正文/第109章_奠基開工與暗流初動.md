# 第 109 章 - 奠基開工與暗流初動

社區醫館一樓的古樸茶案上，幾杯熱氣騰騰的「清心降壓茶」正散發著甘甜的草藥清香。

林品妤將一本厚厚精裝的黑色公文夾輕輕放在茶案中央，伸手將其中兩份蓋有鋼印的公文推到了陸遠與蔡志豪面前。

「法律上來說，所有的備查手續已經百分之百完備。」林品妤聲音冷靜而精準，指著公文上的紅印標籤，「第一份是衛生福利部與法務部聯合簽發的《安康偏鄉長照公益信託基金備查核准函》；第二份是我台北事務所團隊製作的《智財保護法律意見書》。我們對『金草純露』的核心配比實施《營業秘密法》保護，對外圍的超臨界低溫濃縮製程申請發明專利，形成了完整的智財雙軌防線。」

蔡志豪翻開那份備查核准函，看著上面的國家機關印鑑，長長吐出一口氣：「大姊，有你這兩份文件，我們在後山蓋廠房和全台灣推廣 C 級據點，就完全立於不敗之地了！」

陸遠為林品妤斟上一杯溫熱的茶湯，笑著問道：「大姊，台北事務所那邊的工作處理完了，這次能在青海鎮多留幾天吧？」

「明天回台北。」林品妤端起茶杯細品了一口，眼神中透著一絲罕見的放鬆，「老董事長明天也要回台北集團總部召開董事會，正式核撥第二期一億二千萬元的專案資金。我剛好跟他老人家搭同班台鐵列車回去，順便把信託監督委員會的最後章程確定下來。」

次日清晨，後山山腳下的平坦綠地上，喜慶的紅布與紅布條隨風飄揚。

那兩棟廢棄已久的舊鐵皮屋已經被怪手徹底推平，清理出一片空曠肥沃的基址。紅色的工程看板上寫著巨大的標語：「青海養生生技低碳超臨界萃取車間建設計畫」。

青海鎮鎮長、鎮公所秘書、老董事長魏振邦、育幼院陳院長、張伯、廖阿姨舞蹈隊，以及鎮上數十位老街街坊與返鄉青年，全都在山腳平地上齊聚一堂。廖阿姨領著舞蹈隊打響了歡快的鑼鼓，氣氛熱鬧無比。

蔡志豪頭戴一頂亮黃色的工程安全帽，身上穿著筆挺的西裝，手持話筒站在香案前，語速洪亮有力：

「感謝衛生福利部、鎮公所與老董事長的大力支持！今天，青海養生生技萃取車間正式奠基開工！我們將引進全台灣最頂級的超臨界低溫設備，打造全花蓮最具在地溫情與國際標準的養生基地！」

在老街街坊們熱烈響亮的掌聲與歡呼聲中，魏振邦、陸遠、蔡志豪與阿山哥四人共同走向香案前，手持綁著紅絲帶的金鍬。

「第一鍬，開工大吉！」蔡志豪一聲喝彩，四人同時揮動金鍬，將肥沃的黑土重重揚起。

魏振邦拄著拐杖，精神抖擻地看著眼前這片熱火朝天的基址，伸手緊緊握住了陸遠與陳院長的手，老眼中泛著激動的光芒：

「陳院長，小陸大夫，老夫明天就要回台北了。三十年前老院長給我的那五百美元，今天這座廠房和這兩億公益信託，就算是老夫給育幼院和青海鎮鄉親交出的第一份答卷！下個月超臨界設備組裝，老夫一定親自帶台北的生技專家再來老街！」

陳院長眼眶微濕，用力握了握老董事長的手：「魏老，青海鎮永遠歡迎您！」

與此同時，台北市信義區一座高聳入雲的商業大樓頂層辦公室裡。

百葉窗半掩著，將外面的陽光遮擋在大樓之外。

台北大型連鎖藥局與生技連鎖集團「養生堂」總經理嚴崇輝，身穿剪裁合身的深灰色西裝，正站在寬大的班台前。他雙手環胸，冷冷看著桌上擺放的一份剛從衛福部官方網站列印下來的《偏鄉長照公益信託備查公告》，以及一張「青海山泉·金草純露」的內部檢測分析報告。

「超臨界低溫萃取……離土十五分鐘冷鏈……身心同治偏鄉長照據點……」嚴崇輝指尖在桌面上有節奏地敲擊著，聲音陰沉冷拔，「我們養生堂全台五百家連鎖藥局，推了三年的草本複方養生飲，市佔率上個月剛下滑了百分之二。這個花蓮偏鄉的小醫館，從哪裡冒出來的兩億信託？還有這個叫陸遠的年輕大夫，到底是什麼來頭？」

站在對面的法務總監低頭翻開資料，恭敬答道：「嚴總，據我們調查，這個陸遠只是花蓮青海鎮一家舊木造醫館的掌櫃，背後有台北魏氏集團老董事長魏振邦的兩億專款資助。他們剛在衛福部完成了 C 級據點備查，第一批『金草純露』在花蓮已經造成了不小的轟動。」

嚴崇輝轉過身來，冷笑了一聲：「兩億專款？魏振邦那個老傢伙是不是老糊塗了，把資金砸給一個偏鄉赤腳大夫？通知花東分區的商業專員，密切盯緊他們下週一進場的建照進度與藥材履歷。全台灣的植物萃取飲品市場，絕不能讓花蓮這家無名小館翻出什麼浪花來。」

法務總監點了點頭，壓低聲音問道：「嚴總，那我們在智慧財產局的專利檢索要不要同步啟動？」
