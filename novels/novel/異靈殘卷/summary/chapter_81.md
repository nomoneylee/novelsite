# 第 81 章 摘要 - 逃回靈霄峰的絕密藏匿

## 主要情節進展
1. **炸毀絞盤封堵排氣豎井**：姜青鸞沿五百丈垂直排氣豎井鐵梯逆行攀爬，在距地表三十丈處，以僅存的化金酸液毒囊侵蝕青銅絞盤與生鐵鉸鏈，短刀挑斷軸承引發中段十丈岩壁連環坍塌，巨石斷鐵徹底焊死豎井通道，阻斷水牢地面垂直追蹤路徑。
2. **潛回草蘆滅跡自救**：姜青鸞借氣浪衝出豎井，在破曉晨霧與厚雪掩護下避開巡山靈符，自後窗翻回第七峰草蘆。面對急性水銀吸入引起的支氣管灼傷與經脈汞毒，她吞服三粒「清心解毒丹」混以白芨草粉壓制毒性；隨後以赤陽炭火盆將染血外袍、面罩與拭血棉布徹底焚化滅跡，震散餘燼。
3. **辟靈沉香木暗格藏匿鐵證**：姜青鸞以特定頻率叩擊本命信物「萬年辟靈沉香木」藥箱機簧，開啟銀箔絕密暗格，將《延壽天卷》祖師血字拓本、【天字禁忌·癸酉批次上古殘甲移植日誌】絲絹拓本（F009）、三十年五千七百名幼童活體抽髓晶影石、楚小禾牽機蠱解離配方與非人類骨膠原樣品晶管悉數封入，天衣無縫屏蔽外界神識探查。
4. **草蘆對峙與隔門言辭交鋒**：戒律堂巡山掌令孫執事率十數名重甲死士封鎖第七峰小院，以搜捕妖人為名強行扣門欲破門搜查並以靈鑑驗脈；姜青鸞隔門以微觀神經調控發出重疾咳聲，以聖女門規威儀言辭駁斥，並當場點破孫執事頸側人迎穴火毒淤塞、亂服劣質金丹三年必亡之隱疾，震懾強敵。
5. **蘇玉作保與大長老殺至**：長老殿執事蘇玉手持翠玉如意及時趕至小院，以聖女名份與自身名譽強勢逼退孫執事至院外結陣圍困；蘇玉神識傳音示警顧長青即將親率大隊殺至。姜青鸞倚榻運功調息，遠處靈霄峰頂三聲穿雲鑼炸響，顧長青碧綠遁光破空殺來，草蘆大搜查與禁錮死局一觸即發。（章末截斷）

## 關鍵對話/決策
- 姜青鸞：「癸酉-09……十年前被當作廢品拋棄荒原的孩子……陸沉，這座人間煉獄的欠賬，我替你拿到了。」
- 孫執事：「殿下千金之軀，偶感風寒，屬下等身為同門豈能坐視不理？大長老特意賜下『照煞金鑑』與『血魄化毒散』。請殿下開門，容屬下當面驗看脈象，若無異常，屬下自然退避，否則……便是殿下心虛！」
- 姜青鸞：「孫執事，你不過是趙玄風長老座下一條巡山獵犬，何時也學會了望聞問切？你若懂脈象，倒不如先摸摸自己頸側的人迎穴——你每逢初一十五，體內陰虛陽亢，雙目赤紅，那是長期吞服劣質壯陽金丹沉積火毒之象，距離經脈爆裂不過三年之期，你配給本座看脈？」
- 蘇玉（傳音）：「顧長青瘋了。萬壽鼎地底封閉了三千年的九宮陣被炸開，戒律堂在暗渠撈出了化骨堂死士的殘碎骨骼……顧長青已親自帶隊往第七峰來了，半炷香內必到！若妳手頭真有什麼……立刻以火銷毀，切莫留半分痕跡！」
