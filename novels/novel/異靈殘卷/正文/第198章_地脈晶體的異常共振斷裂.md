# 第 198 章 - 地脈晶體的異常共振斷裂

斷脈谷，地下百丈。

這裡是一處遠離上方二號深井、深埋於地底岩盤最深處的太古溶洞裂隙。

昏暗搖曳的晶石火把光芒下，空氣潮濕而熾熱，充斥著滾燙的地火硫磺氣息與岩石被高溫烘烤的焦土味。然而，在這股熟悉的燥熱之中，卻隱隱混雜著一縷令人作嘔的甜腥發酵腐敗氣息。

兩道身披厚重生鉛防護長袍的身影，正沿著一條天然崩裂的傾斜玄武岩裂道，小心翼翼地向著地脈更深處下潛。

陸沉走在前方，腰間懸掛著太乙短刀，左臂暗銀色的幾丁質外骨骼緊緊扣住岩壁凹槽，雙眸中的暗金豎瞳在黑暗中泛著幽微的冷光。

在他身後，姜青鸞依舊戴著那具蒙住雙目的深黑天蠶絲遮光眼罩。雖然雙眼因昨日直視嗜能光錐的火毒尚未完全褪去，但她那敏銳的神經直覺與微觀感知，卻讓她僅憑手中一柄金剛鐵木手杖的輕點，便能穩穩跟上陸沉的步伐。

「慢一點。」陸沉伸手扶住身後的岩角，低聲道，「下方的地質應力極不穩定，玄武岩層的剪切裂隙在擴大，溫度正在急劇下降。」

「溫度在下降？」

姜青鸞的聲音隔著厚實的羊腸防護面罩傳出，透著一絲學者特有的嚴謹與冰冷：

「不合常理。這裡位於斷脈谷地火主脈正上方，岩漿暗河的熱輻射常年維持在七十度以上。地火乃純陽之脈，若非有某種極致的陰寒或高能吸收體在瘋狂汲取熱量，絕無可能出現降溫。」

「妳感應得沒錯。」

陸沉撥開前方垂落的一叢焦黑石鐘乳，目光投向了前方豁然開朗的巨大溶洞空腔：

「前面就是斷脈谷的地脈核心……但情況完全變了。」

姜青鸞微微仰起臉，手杖輕點地面。

呈現在兩人面前的，是一座足有百丈寬廣的宏偉地下地窟。

在地窟正中央，一座高逾三丈、通體宛如赤金琥珀雕琢而成的巨大晶體石柱，宛如一尊擎天巨人的脊樑，筆直地自滾燙的地火岩漿池中央拔地而起，直插溶洞頂部的岩層穹頂！

遠古地脈純陽晶柱！

這是大荒太古時代遺留下來的自然地質奇蹟，亦是維持整個西南板塊靈氣陰陽平衡、鎮壓地心億萬丈深淵幽煞濁氣的天然能量樞紐。在修仙界典籍中，此物被稱為「地脈純陽龍骨」，其內部蘊含的純陽晶髓高達數萬度凝縮能量，正是斷脈谷地火工坊常年能夠引火冶鐵的本源所在。

然而此刻，這根平日裡散發著萬道赤金神芒的純陽晶柱，卻顯得無比病態而詭異。

晶柱表面的金赤光芒，正在以一種肉眼可見的頻率微弱閃爍，忽明忽暗，宛如風中殘燭。

更令人毛骨悚然的是——

在那晶瑩剔透的赤金晶體內部，赫然爬滿了一道道粗細不一、如同死屍體表黑死病斑般的烏黑裂痕！

那不是普通的岩石斷裂，而是某種具有活性的微觀黑色脈絡！

「滋……滋……」

自那些蛛網般的黑色裂縫深處，正源源不斷地向外滲出一股股泛著墨綠幽光的黑色黏液。黑液順著晶柱表面滑落，滴入下方的赤紅岩漿池中，竟沒有被數千度的高溫瞬間汽化，反而如同強酸潑灑在生肉上，發出刺耳的腐蝕沸騰聲，將周圍方圓丈許的赤紅岩漿瞬間冷卻、硬化成焦黑冰冷的石渣！

「黑水……」

姜青鸞即便隔著遮光黑綢，身軀也微微一震，手杖懸在半空：

「是二號深井湧出的那種噬元菌高能母液！它們……它們竟然已經穿透了百丈地脈，直接侵入了純陽晶柱的能量通道？！」

「這不是剛剛侵入的。」

陸沉緩步走近岩漿池邊緣，暗金豎瞳緊緊鎖定晶柱內部的黑色脈絡：

「早在數月之前，甚至數年之前，這些黑水就已經如附骨之疽般寄生在晶柱深處。只是北境葬神天淵的地脈崩塌，引發的超低頻次聲波徹底打破了微觀結構的最後動態平衡。」

「嗡——！」

就在陸沉跨入晶柱十步之內的剎那，異變陡生！

陸沉的左臂猛然劇烈抽搐！

那覆蓋在他小臂與手背上的暗銀色幾丁質外骨骼，內部成千上萬條微觀神經觸突同時瘋狂痙攣！

原本緊密咬合的六角密堆積幾何甲片，竟在無自主意識操控的情況下，一片片狂暴地豎立而起，宛如受驚的凶獸炸開了渾身的骨刺！

甲片深處，那深嵌在遠古生化骨骼上的淡金色古代代碼，以前所未有的速度在視網膜上狂暴刷屏：

【CRITICAL ALERT / 地脈核心能量塌陷預警】

【PROTOCOL ERROR / 檢測到三型高能噬能生物集群】

【SYSTEM OVERRIDE / 立即終止物理接觸 / 撤離半徑：三千米！】

警告！

源自螭吻太古基因庫深處的最高級別滅頂警告！

與此同時，一股冰冷暴戾、充斥著物種面臨滅絕時的極致恐懼感，順著左臂神經通道轟然衝入陸沉的識海，震得他體內凝核期中期的冰魄息核猛烈一晃，喉頭湧上一絲甘甜！

「陸沉！」

姜青鸞敏銳察覺到陸沉氣息的驟變，快步上前伸手搭在他的右肩上：「不要靠近！那晶柱現在是一個高度不穩定的能量黑洞！」

「我沒事。」

陸沉深吸一口氣，強行以鋼鐵般的理性意志鎮壓下左臂螭吻的原始暴走，沉聲道：

「這尊太古晶柱……內部已經空了。」

「空了？」姜青鸞眉頭緊蹙。

「對，全空了。」

陸沉死死盯著那三丈高的巨大赤金柱體，太乙短刀在掌中緩緩旋轉：

「在我的微觀感知中，晶柱表面雖然維持著純陽二氧化矽晶格的硬度，但其內部直徑兩尺的核心能量管道……早已被數以兆億計的噬元真菌吃成了海綿般的微孔蜂巢結構。」

「整根柱體，現在只剩下一層薄如蟬翼的脆性外殼，依靠著兩端玄武岩地應力的相互擠壓，才勉強沒有當場崩碎。」

「但是……外力的平衡，馬上就要被打破了。」

話音未落。

「咔嚓！」

一聲清脆得如同琉璃墜地的脆響，突兀地自地窟中央炸開！

陸沉與姜青鸞的瞳孔同時驟然放大！

只見那根高達三丈的赤金純陽晶柱中央，一道長達一丈的巨大裂縫，如同一條撕裂天地的漆黑雷霆，自黑水最濃稠的凹陷處猛然暴裂蔓延開來！

「咔……咔嚓……轟隆隆——！」

連鎖反應！

在微觀晶格徹底斷裂的瞬間，微觀層面的分子鍵崩潰如同骨牌般引發了宏觀物理結構的絕對雪崩！

「退後！！」

陸沉暴喝一聲，左臂幾丁質外骨骼瞬間橫推而出，將身旁的姜青鸞死死護在身後！

下一微秒！

整座高達三丈、重達數十萬斤的遠古地脈純陽晶柱，在兩人眼前發出了一聲宛如史前巨獸臨死前的淒厲悲鳴，自正中央轟然斷裂成兩截！

「砰————！！」

如同天地開闢般的沉悶爆鳴聲在封閉的地下溶洞中轟然引爆！

斷裂的巨型晶體狠狠砸落進下方的岩漿池中，激起數十丈高的熾熱熔岩狂瀾！

然而，預想中赤炎焚天的景象根本沒有發生！

在晶柱斷裂的核心橫截面上，沒有噴出任何純陽烈焰，反而噴湧出了一道沖天而起、厚重黏稠如黑色狼煙的滔天魔煞黑水！

「呼————！」

那是被地脈純陽晶柱壓制了整整八千年的地心古魔真煞！

黑水狂風如九幽陰風般席捲而過，所過之處，原本熾熱翻滾、溫度高達千度的地火岩漿，竟在短短三息之內被那股極致的嗜能寒煞徹底冰封！

紅色的熔岩之海，轉瞬間化作了一片泛著漆黑腐臭氣息的死寂黑岩！

地火……熄滅了！

維繫斷脈谷地火工坊鍛造、為全谷五千人提供地熱與能量平衡的地脈主火，在純陽晶柱折斷的這一瞬，徹底灰飛煙滅！

而晶柱斷裂所引發的地質災難，才剛剛開始！

「隆隆隆隆——！」

支撐著整座地下百丈古溶洞穹頂的承重晶柱一旦斷裂，千萬噸計的玄武岩頂板瞬間失去了核心支撐！

無數條寬達數尺的巨大裂縫如狂蟒般在洞頂瘋狂蔓延，粗逾數圍的石鐘乳與重達萬斤的玄武岩巨石，如冰雹般自百丈高空呼嘯砸落！

「要塌了！」

姜青鸞俏臉冰冷，手中的導盲鐵木手杖在飛石砸落的氣流中穩如泰山：「地脈純陽封印已破，地殼正在發生局部剪切坍縮！」

「走！」

陸沉眼神冷徹如刃，沒有絲毫的猶豫與恐懼。

面對頭頂轟然砸落的一塊足有磨盤大小、攜帶著萬鈞下墜巨力的尖銳岩石，陸沉身形微側，右手太乙短刀連鞘暴斬而出！

「鏘——！」

刀鞘重重轟擊在飛石的重心薄弱點上，暗勁催動，磨盤巨石竟被硬生生凌空偏轉三尺，狠狠砸在兩人身側的石壁上爆碎成漫天齏粉！

與此同時，陸沉長臂一攬，精準無比地將姜青鸞緊緊箍在自己的左側懷中。

蜂巢中空骨骼，減重全開！

晶石纖維強化阻尼，加載！

140 米每秒神經超頻，瞬間啟動！

「唰！」

陸沉腳下的碎石地面瞬間炸開一圈氣環，整個人如同一頭自深淵中狂飆突進的暗夜獵豹，在狂暴砸落的落石雨中拉出一串令人眼花繚亂的極限殘影！

左前方，一尊丈許方圓的巨型石柱轟然砸落！

陸沉暗金豎瞳微觀鎖定零點零一秒的空隙，身軀在半空中以一種違背人體關節極限的奇異姿態側滑扭轉，左臂暗銀外骨骼「砰」地一聲借力拍擊在崩塌的石壁上，整個人如彈簧般折向右側狹窄的裂縫通道！

「轟！轟！轟！」

身後的古溶洞在以每秒數十丈的速度連環崩塌，方才那根斷裂的純陽晶柱與熄滅的岩漿池，轉瞬間便被千萬噸滾落的花崗岩徹底活埋吞沒！

冰冷黏稠的黑水氣溶膠順著塌陷的氣壓逆流狂湧，緊緊咬在兩人的腳後跟後方！

百丈、八十丈、五十丈……

兩人在生死一線的岩縫中逆著落石狂暴突擊！

「咔嚓！」

前方生鐵絞車平台的固定懸臂，已經在劇烈的地震中扭曲變形，兩根承重鋼索崩斷了一根，吊籃在半空中劇烈晃蕩！

「抓緊了！」

陸沉在距離平台尚有五丈的半空中厲喝一聲。

他右臂猛然揚起，掌心那柄淬過黑蛇毒液的太乙短刀倒扣，刀柄末端繫著的一根由天蠶金絲與烏金絲混編的百丈攀山索，如毒龍出洞般激射而出，死死纏繞在上方未坍塌的天然花崗岩石樑之上！

「起！」

陸沉全身肌肉如絞索般暴凸，雙臂借著鋼索的巨大拉力凌空翻滾，身形在半空中劃出一道驚心動魄的弧線，在下方絞車平台徹底崩塌墜入深淵的最後半瞬，抱著姜青鸞轟然踏上了通往地表第一層的堅固主坑道！

「轟隆隆隆————！」

伴隨著最後一聲驚天動地的悶響，整條通往地下百丈古溶洞的裂隙，在兩人身後徹底被落石與黑水堵死！

滾滾煙塵自石縫中噴湧而出，嗆人肺腑。

主坑道內，數十名手持穿雲重弩、滿臉焦急的異靈鐵衛死士與鐵爪等人正瘋狂搬運碎石，突然見到陸沉抱著姜青鸞破塵而出，所有人頓時發出了一陣劫後餘生的驚天狂呼！

「城主！姜研析長！你們出來了！！」

「天佑斷脈谷！！」

鐵爪扔下手中的生鐵大鎬，撲通一聲跪倒在地，虎目含淚。

陸沉將懷中的姜青鸞輕輕放下，隨手擦去臉頰上被碎石劃破的一道微弱血痕。

他體內的氣息在短短數息內平息下來，息核運轉沉穩依舊。

「城主，地下到底怎麼了？方才整個山谷都在晃，地火爐子全滅了！」鐵爪顫抖著問道。

陸沉沒有立刻回答。

他轉過身，冷冷注視著身後那座被徹底封死的幽暗坑道，掌心短刀緩緩插回鞘中。

姜青鸞站在陸沉身側，素手輕輕揭開了遮光黑綢的一角。

雖然她的雙眸依舊泛著充血的微光，視線尚有些模糊，但她那清冷澄澈的眸子，卻倒映著坑道縫隙中滲出的一縷冰冷黑氣。

「大荒的太古封印……已經徹底完了。」

姜青鸞的聲音平靜得沒有一絲波瀾，卻讓在場的所有鐵衛骨髓生寒：

「純陽晶柱斷裂，地火靈脈永久熄滅。」

「從這一刻起，大荒西南將不再有純陽靈氣庇護。」

「地脈深處沉睡了八千年的萬古魔煞……已經掙脫了最後的枷鎖。」

陸沉按刀而立，面容冷酷如雕塑：

「傳令下去。」

「全面封死一號、二號主坑道，用微磁灰漿混合玄武岩水泥，將這座坑道澆築三丈厚鉛石重壁！」

「地火已滅，通知地火工坊工匠，全面轉向符陣蓄電池與風力機關。」

「真正的天災……已經到了門口。」

「這一次，大荒不會再有任何奇蹟。」
